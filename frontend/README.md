# Fairwork frontend

React + Vite + TypeScript app for the Fairwork MVP.

## Commands

```bash
cp .env.example .env
npm install
npm run dev      # http://localhost:5173
npm run lint
npm run build
```

Set `VITE_API_BASE_URL` to the backend origin (default `http://localhost:4000`).

Project-wide setup, demo script, and known limitations: [`../docs/DEMO_AND_STATUS.md`](../docs/DEMO_AND_STATUS.md) and [`../README.md`](../README.md).
